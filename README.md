# Chronoclicker 4.1

Кликер об истории человечества: от камня и огня до сингулярности.

**Играть:** откройте `index.html` в браузере или включите GitHub Pages (Settings → Pages → Deploy from a branch → main → / (root)).

## Как устроена прогрессия
- Добывайте ресурсы кликами и стройте здания.
- Чтобы перейти в следующую эпоху, прокачайте **все здания текущей эпохи на MAX**.
- После этого откроется технология перехода (например, «Земледелие» → Медный век).
- Прогресс сохраняется в браузере автоматически.

## Технически
Один файл `index.html` (около 3 МБ), без сборки и зависимостей. Звук синтезируется в браузере.
